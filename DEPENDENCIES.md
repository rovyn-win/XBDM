# Build requirements

You’ll need the Xbox 360 SDK and the header files listed below. These headers aren’t included in this repository for copyright reasons, and your SDK installation may not include all of them.

Place copies in `xbdm/imp/`. Git ignores this folder. You can also keep them elsewhere and add that folder to your compiler’s include path.

Required headers:

- `KernelExports.h`
- `XeCrypt.h`
- `automation.h`
- `cabinet.h`
- `consolecert.h`
- `contentpkg.h`
- `kernelp.h`
- `ntstatus.h`
- `xamcache.h`
- `xamdbg.h`
- `xamp.h`
- `xboxp.h`
- `xcabinet.h`
- `xdbg.h`
- `xex.h`
- `xexhv.h`
- `xinput.h`
- `xonlinep.h`

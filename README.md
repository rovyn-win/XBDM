<h1 align="center"><strong>XBDM (Xbox Debug Monitor)</strong></h1>

Source code for XBDM (Xbox Debug Monitor), a commonly used debugging and development tool for the Xbox 360.

Originally created by Nathan LeRoux, this fork was optimized and tweaked to fix compatibility with [OpenRPC](https://github.com/rovyn-win/OpenRPC)/JRPC2. This plugin can act as a fully functional replacement for `xbdm.xex` if you already have it in your DashLaunch.

Licensed under the [MIT License](LICENSE).

Platform headers are supplied separately, you must acquire them if you want to compile this from source. <br>
Please read: [DEPENDENCIES.md](DEPENDENCIES.md).
